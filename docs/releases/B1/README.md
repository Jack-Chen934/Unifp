## 3. 已有实验信息：取得了什么效果

### A基础复现有效

V6 r2 seed1 A8000的S0／S1／S2冻结TCP L2为2.06／2.09／2.27 cm，288个episode零物理失败，各组通过已确认门槛。它证明当前模型与学习流程具有基础跟踪可行性，不等于多seed或完整力控复现通过。

### B学到了部分力信息，但闭环控制不足

| 同协议冻结均值策略R2 | 9000 | 12000 | 16000 |
|---|---:|---:|---:|
| 非零任务段补偿TCP L2 | 13.35 cm | 34.34 cm | 29.76 cm |
| 物理失败／96 | 0 | 14 | 3 |
| 非零外力估计L2 | 15.33 N | 16.45 N | 16.93 N |

力估计相对A零力父有改善，但随训练延长没有持续提升；12000→16000跟踪与失败部分恢复。16000零力三组TCP约8.3 cm，精度相对A遗忘；真实墙10 N／20 N接触各0/48成功，B未验收。不能把注入外力估计、补偿位置跟踪和真实接触按压力视为同一项能力。

训练高斯采样的步数加权TCP：15001—16000为28.79 cm，16001—17000为26.30 cm，17001—17740为24.84 cm；奖励率2.882→3.133→3.308，完成episode失败率7.54%→3.66%→2.75%。末窗口740轮，正式冻结评估仍只到16000；不能用训练采样替代评估，也不能用17923单轮值宣布恢复。

| 源码／存档 | 四段训练计数连续、创建时恢复物性、双Adam与RNG续训通过 | 有可靠基线身份；不是只加载权重的续训 |
| 坐标与命令 | 命令／外力坐标、目标变化和接口审计未发现确定接线错误 | 不能据曲线宣称方向全反；命令力→动作利用仍可做匹配状态检查 |
| 奖励 | 23项能重建实际奖励，符号和dt核验通过 | 未证明记账bug；权重适配仍可研究，但不能因惩罚变大就直接降低权重 |
| 可达性与负载 | 少量补偿越界／静力超额，不能解释普遍退化 | 不支持将任务整体不可行定为唯一根因；应分层评估而非滤掉难例 |

| Critic／GAE | 三checkpoint只读检查；249窗口与原代码GAE一致；五秒目标偏差约+0.018／−0.043／−0.044 | 未发现整体同向价值失控；单随机后续仍含自举，不能证明局部动作排序准确 |
| 探索与限幅 | 同状态增大std显著增加请求限幅；joint2短测限幅10.07%→45.23%→59.67% | 最有直接证据的优化入口之一；不是电机必然先天不足的证明 |
| 均值策略 | 12000去噪后跟踪仍差；轮速和关节目标裁剪增多 | 不能只调整回放噪声；需让训练得到更好的均值策略 |
| 熵干预 | 同9000父各200轮，零熵降低限幅和训练失败，但冻结R2为13.80 vs13.88 cm，接触仍零成功 | 去熵不是已验证完整修复；不把短测结果升级为长期结论 |
| 速度 | 每轮约96%耗在采样侧、4%网络更新；存在逐episode P95和CPU同步 | 已定位到采样侧，尚未做细分profile；不能只凭GPU瞬时利用率判瓶颈 |

## 5. 下一版的优化优先级与边界

下表是根据证据提出的研究建议，**不是已经批准的新数值配置，也未实施业务改动**。具体参数应按项目流程记录、讨论并拆票；所有候选必须与B1在同父检查点、同训练预算、同冻结评估下比较。

| 顺序／模块 | 推荐方向 | 必须观察什么 | 暂不做什么 |
|---|---|---|---|
| P0：采样性能 | 短时profile物理、reset统计、P95、CPU/GPU同步和日志；优先减少不改变训练语义的开销 | 实际秒／轮、随机数与转移时序、统计口径、同配置回归 | 不先减少环境数、放大步长或降低碰撞精度 |
| P1：动作与执行 | 按转向／驱动／臂的实际单位、PD和effort评估探索尺度；独立比较std约束或熵调度；若研究action_scale，单独一组 | 各关节全子步限幅、连续限幅时长、目标裁剪、均值R2及零力保持 | 不同时改std、PD、effort和奖励；不凭空提高电机力矩上限 |
| P2：命令／目标闭环 | 对同类姿态、力方向和底盘状态区分命令力与实际外力响应；检查均值动作是否利用任务输入 | 误差收敛方向、受力切换响应、命令敏感性、接触未触达／过冲／挤压分类 | 不用冻结world目标误判随底盘移动的正式目标 |
| P3：课程与V3条件 | 在最终±60 N、底盘运动和原验收任务不变的条件下研究分阶段难度、幅值／目标分布与零力保持 | 到最终同难度后的R2、S0/S1/S2和接触成功率 | 不把缩小任务后的易题成绩当原任务复现完成 |
| P4：奖励与辅助耦合 | 结合实际梯度和动作变化分解，单独比较奖励平衡、辅助lr／权重等候选 | 同输入更新前后动作、零力遗忘、估力与均值跟踪是否同步改善 | 不因可解码力而默认latent已被Actor正确利用 |
| P5：Critic／PPO | 若前面结果仍不足，检查匹配状态多后续的局部校准、危险状态优势与实际更新方向 | 局部低估／高估、GAE信号、样本覆盖、KL与策略变化 | 无证据不先重写PPO、扩大Critic或更换网络结构 |

性能优化可先于训练参数适配；参数实验从完整状态承接，不能只载权重重建Adam后称单因素对照。动作参数改变可能影响状态与学习配置身份，应显式记录允许差异；评估门槛不根据结果追改。B1继续原预算到24000／32000／40000的结果可追加为同基线后续证据，不能回改本次冻结证据截点。
