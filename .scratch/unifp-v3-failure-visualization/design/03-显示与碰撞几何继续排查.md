# 显示与碰撞几何继续排查

摘要：用户要求继续排查；本议题仅执行隔离诊断，任何业务修复另行形成明确修改方案。新工具不接入训练调用链。

Q：先以什么证据区分显示与装配／物理错误？

A：读取冻结资产，在无重力、固定底盘且关闭自碰撞的独立静态场景中，只对比flip_visual_attachments=True／False，摄像头明确使用visual和collision两种几何；读取实际DOF名称和刚体pose，对照相同关节位置的URDF FK。若物理pose相同而显示不同，说明至少存在纯显示变换因素。该静态场景不作为训练动力学验证。

Q：怎样继续分析已捕获接触？

A：按Gym真实DOF名称映射保存关节角，从base_link重建所有link的4×4变换；转换视觉／碰撞网格到同一底盘坐标，检验相交及表面距离。判据与坐标以米／弧度表示，区分可视外形、URDF代理和PhysX实际接触余量。只有保存的终止帧，不能据此重建此前子步或逐次归因历史1648次。

接口框架：

```python
static_probe(urdf, output_dir) -> native_body_poses_and_images
geometry_audit(urdf, dof_names, failures) -> per_pair_geometry_evidence
```

单元验证：变换闭合、名称对应、visual与collision输入可追溯；整体验证：静态原配置确实复现画面异常、单变量显示对照、实际Gym刚体与独立FK比较、失败姿态成对几何检查和截图。本轮不改变训练／模型／终止阈值。
