# 动作请求与执行分解：任务范围

用户授权实施只读诊断前两项：区分均值／探索对执行限幅的影响，检查受力变化后的TCP与补偿目标响应。继续使用正式V6、原B事件分布、原PD和终止规则，不修改业务源码，不更新策略、不启动新的训练分支、不停止正式seed1。

使用9000和12000存档，各运行均值／采样两种独立128环境×20秒轨迹；在每条轨迹的同一物理子步状态下，反事实计算均值、当前std采样、9000std采样的动作请求。反事实只计算，不向仿真提交；实际执行仍调用原控制器。完整记录目标裁剪、PD分量、力矩限幅与受力／TCP时间序列。

完成含义：原控制器与分解器数值一致，得到各关节均值／采样限幅及重叠分类；在真实受力事件附近分别展示TCP运动、目标运动和误差变化，保留reset／push和失败样本，不将相关性当唯一因果。详细脚本和原始数据均可复核。
