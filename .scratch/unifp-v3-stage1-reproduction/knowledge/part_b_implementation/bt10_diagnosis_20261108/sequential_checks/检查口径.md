# B策略退化：顺序只读检查

用户授权按共享latent、奖励权衡、力矩饱和与可达性依次检查。本任务只增加独立分析脚本与证据，不修改业务源码、训练参数或正在运行的正式进程，不启动新的正式训练。

源码事实：`v3_actor_critic.py:154`附近将当前58维与历史编码64维拼接后生成动作；Decoder从同latent输出12维监督预测。`v3_ppo.py:57`附近定义共享Encoder的两个优化器，`:208—264`执行20组主／辅助更新。`legged_robot_v3.py:968`附近保留23项原始奖励并按权重和dt求和；`:1010`按真实注入力与命令力计算K200补偿目标；`:1550`附近执行位置／轮速与力矩限幅；`v3_kinematics.py:65`提供活动URDF的TCP前向运动学。

顺序与信号：

1. 相同真实历史输入下交叉组合9000／10000／12000的Encoder和Actor，分开量化表示变化与Actor变化。混合网络是离线探针，不能把输入分布不匹配直接归因于错误。随后在独立进程采集真实24步rollout，使用恢复的双Adam仅在内存副本执行一轮原PPO，逐次观测主／辅助更新前后的动作、估力和Encoder梯度夹角；此更新不保存策略、不回到正式run。
2. 先按正式训练episode日志步数加权复算23项真实奖励贡献；在三个检查点的独立128环境×20秒采样中回读原始奖励并验证逐步总和。区分奖励数值贡献、策略梯度与因果，不用某一惩罚占比直接决定改权重。
3. 同一新采样记录全部8个物理子步力矩限幅，统计持续时长，并在reset前保存root、关节、真实／补偿目标和力。可达性先用链长必要界给出确定的固定root不可达样本，再用带关节限位的多起点数值IK给出找到的可行解；IK失败不等于不可达，固定root不可达不等于移动底盘永远不能达到。静力估算区分外载、重力、惯性和实际动态力矩。

正式训练保持到16000观察。每一阶段输出原数据、分母、单位、限制与中文结论，最后同步统一进度；若发现新业务修复需求，只记录证据与建议，不在诊断中实施。
