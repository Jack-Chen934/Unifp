# 命令力—目标—Actor输入审计

目的：用户授权继续只读定位，检查命令力与目标坐标、缩放、发布时序、网络调用链，以及固定真实输入下策略对正负命令力的敏感性。正式seed1继续原参数训练，不修改业务、资产、奖励、网络或优化器，不启动新训练。

范围：执行原帧构建／补偿方法的tensor级确定性审计，复用七组真实观测，对9000／10000／12000策略做同输入反事实推理。输出完整数据、坐标／单位／索引依据与中文报告；敏感性不能冒充真实动力学正确性。

完成：确认命令到Actor可见槽位、Critic补偿目标与世界公式一致，历史发布新旧帧不混淆；量化小扰动／有限正负命令的动作变化与直接／Encoder路径影响，并保留原数据身份和训练正常运行快照。
