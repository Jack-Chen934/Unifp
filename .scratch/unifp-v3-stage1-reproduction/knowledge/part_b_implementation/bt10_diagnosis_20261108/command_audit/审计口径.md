优先假设H1：索引／缩放有误，原构建函数输出将不等于手算命令槽与球坐标；H2：坐标或时序错配，yaw扫描／applied-vs-pending／history发布将与世界公式不一致；H3：链路正确但策略对力命令响应弱或改变，固定输入正负扰动会表现出不同的力命令／等效几何目标动作变化。前两项可用确定性断言判断，第三项只是表征线索，不能直接断言动作正确或唯一根因。
