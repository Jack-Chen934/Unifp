# 标准差更新来源检查

本任务继续定位B阶段9000至12000轮的探索标准差增长。范围为已保存真实rollout、策略、双Adam和实际学习率的离线分析；仅在独立进程内存副本上观察现有PPO更新，不保存修改后的策略，不启动新的闭环训练，不修改正式训练或业务代码。

当前调用链为历史观测→Encoder→Actor高斯均值与14维可学习std→原始采样动作→环境裁剪／PD；PPO主损失更新Encoder、Actor、Critic和std，辅助更新仅更新Encoder／Decoder。完成意味着给出std即时梯度与实际Adam更新的可复算证据，核验观察器不改变原更新，并明确小rollout诊断不能代表4096环境长训练因果。
