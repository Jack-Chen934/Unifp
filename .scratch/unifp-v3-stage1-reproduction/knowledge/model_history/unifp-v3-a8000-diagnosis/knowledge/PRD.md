# A8000异常排查任务简介

本任务针对2026-11-04已完成的V3 A8000结果：末端追踪有效，但S1／S2底盘运动跟踪失败；离线分析另发现reset后首步末端误差大跳变与驱动轮目标频繁硬裁剪。

范围：在已完成隔离诊断的基础上，修复V3 TCP真值和reset初始化，生成独立平滑滚动碰撞资产并标定低层控制，补齐真实GPU回归与运行身份。用户于2026-11-04批准按分模块推荐计划实施。

当前链路为Actor动作→环境动作裁剪→转向／机械臂位置目标和驱动轮速度目标→显式力矩→GPU PhysX→状态／奖励／目标推进／局部reset→观测。首步与轮系两个症状分别涉及后半段状态一致性及前半段执行能力。

约束：训练仅在远程；保留官方副本、正式源码快照、8000轮权重、已封存评估和所有原始证据；不进入B，冻结验收标准不变；业务修改仅位于V3开发副本，新远程候选快照与旧训练快照隔离，完成回归前不启动正式长训。诊断使用空闲GPU、小环境数、固定seed，并将所有配置差异明确标为隔离对照。

完成含义：原reset复现转绿，独立新资产的带载前后／侧移／旋转达到已确认候选容差，相关单测和分规模真实运行／恢复回归通过，形成新身份与完整实验记录。其他Go2W／Piper开发内容不属于清理范围。

训练观察作用：记录健康状态、失败episode和冻结评估，不因单次物理失败额外停止全局训练；环境按官方语义reset并继续，非有限状态与执行异常仍退出。A验收保留全部失败样本和已冻结阈值。相同业务身份的完整边界允许在独立新run恢复，父run与旧观察规则记录保留。
