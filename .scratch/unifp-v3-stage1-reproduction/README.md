## 运行与开发衔接

```text
00—03共同基线
  → A04—A11设计 → A票据确认 → 实现／测试 → 冻结A启动0→8000
                                           ├→ A8000零力评估／完整checkpoint
                                           └→ 隔离进行B设计／票据／实现／短测
  → 两项均通过 → B恢复学习状态并续训8000→40000
  → 配置协议冻结后的正式seed1／2／3六类验收 → 用户验收 → 轮式创新
```

此处先运行的是开发seed0；正式种子须在A＋B协议冻结后各自从头执行，不把开发训练自动计入正式验收。A先结束则停在8000等待；B先就绪也不提前启力。A初步指标未通过时先分析并确认调整，不自动追加轮数。完整学习状态包括主／辅助优化器、RNG和准确计数等，默认不承诺PhysX内部状态逐比特恢复；正式分段协议须预先冻结并披露。详见总体计划，不以仅加载权重替代续训。
