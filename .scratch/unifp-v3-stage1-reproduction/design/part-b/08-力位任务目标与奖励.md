推荐采用下列合同：


奖励在step结束、reset和命令推进之前，用本次区间实际F_ext及本次F_cmd结算；禁止误用下一次事件峰值、decoder估力或净接触力来替代F_ext。后继Critic仍按B04／B06的后继命令与已施加力构帧，不能为共享公式而复用过期的奖励目标。两路合力为零时，世界目标回归几何目标；Critic球坐标零合力分支按B06直接沿用原几何命令，保持A零力回归。

#### 两种误差分别表达不同问题

```text
e_geo_world[N,3]  = p_tcp_world - p_geo_world     # m
e_comp_world[N,3] = p_tcp_world - p_comp_world    # m
```

两组均计算世界坐标L1和L2，单位m；L1直接对应末端指数reward的误差，L2用于与此前TCP物理误差曲线连贯比较。训练的末端优化目标为e_comp；e_geo是任务表现指标，不能在非零力下仍要求无条件趋零。例如几何目标X=0、人工力+20N且命令力零时，补偿目标X=0.10m；TCP恰在0.10m时，e_comp=0而几何L2=0.10m，这是目标关系导致的位移，不是10cm控制失败。

相反，几何误差很小而补偿误差较大，可能意味着策略仍在刚性追踪旧几何点，未学会所需柔顺。命令力与人工外力相反且匹配时，补偿与几何目标重合，才能直接以几何精度检验对应任务；独立扰动条件则同时查看两条曲线。只看总reward也不充分：alive、底盘及正则贡献可能掩盖末端项变化，应同时记录末端raw项与物理误差。匹配力、独立外力与两路零力评估分组在B10冻结，不在本题先定阈值。

#### 三种“力”与正负号

| 信号 | 物理含义 | 本场景用途 |
|---|---|---|
| F_ext_world | 脚本提交的人工外力 | 始终0N，不充当接触反力 |
| F_contact_on_robot_world | 物体对机器人实际接触反力 | 独立测量真值，具体提取方式留Q3b |
| F_hat_ext_yaw | decoder从历史估计的末端外力 | 按B05缩放还原为N并转换坐标后，与反力作接触泛化对照；不作为动作反馈 |

定义单位法向n_world从机器人指向墙，正命令f_cmd表示机器人希望沿n方向按压。稳定接触时，理想物体反力指向−n，即F_contact_on_robot≈−F_cmd_world；绘图若希望均为正按压力，比较f_cmd=dot(F_cmd_world,n)与f_contact=−dot(F_contact_on_robot_world,n)。decoder预测的是机器人所受外力，同样投影为−dot(R_yaw F_hat_ext_yaw,n)，不能直接与正按压力相减后误判反号。

创建阶段先沿用V3机器人创建、固定关节／碰撞过滤与名义物性设置，再在prepare_sim之前创建每环境wall。通过Gym的DOMAIN_SIM接口一次取得robot_actor_indices[N]、robot_body_indices[N,B_robot]及wall_body_indices[N]，不能用env_ids、2*env_id或假定创建顺序替代真实索引。映射在启动时检查一次，不每策略step扫描名字／资产。

保留全局Gym包装张量的完整形状和引用寿命；评估类按索引读入持久的机器人逻辑缓存。高级索引结果是副本，不能假设修改逻辑root会自动更新Gym原始张量：reset需显式scatter到完整root张量，再将完整原生root／DOF张量和选中机器人的全局actor索引传给indexed setter。只提交done机器人，不改wall和其他环境。无DOF墙不占力矩槽；set_dof_actuation_force_tensor继续提交机器人全部14N力矩，不为墙伪造关节。

人工外力在接触评估中恒为零，复用B04的非零外力提交接口但由接触类实现零注入行为，不把[N,B_robot,3]误当包含wall的全局刚体力张量交给Gym。F_cmd保持非零任务命令；不将墙力scatter到任一人工力槽。

#### 最小代码接缝与调用时刻

源码存在两处原生绑定：继承的`envs/base/legged_robot.py:_init_buffers`在基类构造期间初始化root／DOF／接触张量，V3构造后段另绑定rigid_state；两者都早于首次reset使用。推荐仅在V3副本中提取这些现有绑定和reset写回，不改官方`UniFP/`。不得先运行单actor错误view、等构造结束后再替换。

| 窄接口 | 原训练默认实现 | 接触评估实现 |
|---|---|---|
| `_bind_simulation_tensors() -> None` | 将复制版基类_init_buffers的现有acquire／view前缀原样提取，随后继续原缓冲区分配 | 保存完整root／DOF／接触张量，绑定[N,13]及[N,B_robot,3]逻辑缓存；调用时映射已经创建 |
| `_bind_robot_rigid_state() -> None` | 原V3 acquire＋[N,B_robot,13] view | 保存全刚体状态，按robot_body_indices初始化原逻辑shape |
| `_sync_robot_state_tensors() -> None` | 原绑定即原生视图，无额外操作 | 原生refresh后更新逻辑root／rigid／contact缓存；首次初始化、reset回读及策略区间结束时调用 |
| `_commit_robot_reset(env_ids: Tensor[K]) -> None` | 原reset_idx中两次indexed setter的逻辑原样提取 | 显式scatter逻辑root到全局root，使用DOMAIN_SIM robot actor ids提交完整root／DOF张量 |
| `_after_physics_substep(physics_index: int) -> None` | 空操作，无刷新／复制／日志 | 刷新接触张量，按索引copy到[N,8,3]wall／finger力缓冲；子步内不写文件 |

上述方法分别有真实的训练／评估调用方，仅隐藏原生布局差异，不增加backend适配层。命名可在拆票时与同职责的B04接口合并，不能重复建立两组同义刷新／施力方法。提取不改变默认训练函数原计算顺序、dt、物性应用时序或控制输出；在A→B允许差异清单中记录必要源码字节变化，并用零力与无墙短测核对行为。

子类按既有目标段初始化／推进接口提供固定场景命令，step保留“执行→结算→推进下一命令→终止快照→局部reset→发布观测”的B04顺序，不在脚本中先取得旧历史动作、随后才改命令，也不为了塞入测量而多simulate一步。reset清该环境的测量有效位、8点缓冲和评估episode阶段；再次发布时历史包含已经设置好的命令。物理失败或timeout仍只reset对应环境，失败原因和reset前测量进入归档。

#### 固定世界点与原任务坐标的衔接

墙与参考几何点按Q3b冻结在每环境世界坐标。底盘自由运动会改变任务中心和yaw，固定世界点不等于永远保持同一球坐标三元组：评估子类每次发布观测前，用B06的world→task球坐标转换表示当前脚本世界目标，Actor仍收到原来的三维几何命令，不加新输入或墙真值。接近轨迹从reset TCP到固定世界参考点，保持段世界点不随底盘漂移；相应`_geometric_target_world()`在该子类返回当前脚本世界目标，普通训练仍沿原命令还原方法。

该世界目标脚本不依赖测得反力或decoder，按episode时钟推进；具体插值、各段时长和释放时是否增加退离点在B10协议冻结，不在本项添加位置／力反馈控制器。法向力命令也从固定世界n表示成当下yaw命令槽。yaw、目标转换时间与本区间所用命令在trace注明，不能在reset前后混用。观测范围超出训练采样域时记录真实命令与已有clamp情况，不偷偷移动墙或裁剪脚本目标以改善结果。

#### 推理身份、输出与失败语义

加载明确B checkpoint并核验有效训练父身份、模型／动作／schema／V6资产和控制时序；接触场景单独记录评估身份与源码、名义物性、wall、脚本和manifest SHA。明确区分“训练来源相同”与“评估场景不同”，不能要求有墙的评估全配置hash等于无墙训练，也不能因此跳过全部模型／资产兼容性核验。与A8000的接触对照留B10，使用相同冻结场景，不假称A本就有受力能力。

入口仅构造策略与环境，不创建Runner、storage、主辅optimizer，不调用学习器load去恢复4096环境物性／push／训练RNG。使用评估自己的seed及Q3b名义物性、原模型state_dict严格加载，模型eval＋inference_mode；训练文件和目录只读。评估I／S／C仅作为来源字段，不调用训练set_progress推进或修改存档，接触episode／策略步单独计数。

输出保持窄布局：metadata、包含8点力和动作前估力的policy_trace.jsonl、逐episode结束类别与接触有效性记录、summary，以及便于观看的力曲线／TCP轨迹和短视频（视频沿用现有回放渲染方法，不实现新渲染引擎）。B10定义最终字段、规模与阈值；原始失败样本保留，视频不能替代数值归档。

NaN、原生执行异常和输出写入失败按B07退出并尽力保留诊断；测量无效或非预期接触保留为独立评估类别，不自动改模型／阈值、不成为训练全局停训条件。wall读数不可用或同身份无墙回归不一致时，先记录证据再回到相应接口修正，不能把失败路径换成策略估力作为“真值”。
