模型装配继续由Runner传`num_privileged_obs=294`及`critic_hidden_dims=[512,256,128]`，其余Actor／encoder／decoder／std沿A05。环境配置单帧98、c_frame_stack=3，派生总宽294；首层权重[512,294]、随后[256,512]／[128,256]／[1,128]，模型和环境配置必须一致。

| 调用方／接口 | 完整签名与shape职责 | 状态、失败及验证接缝 |
|---|---|---|
| 环境step／reset构造单帧 | `_build_frames(self, env_ids: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]`；输入long[K]，输出干净Actor[K,58]、Critic[K,98]、标签[K,12] | 与A04同接口，无历史／噪声／采样物性副作用；数据同边界，缺字段／非法值失败 |
| 环境step／reset发布 | `_publish_observations(self, env_ids: torch.Tensor) -> None`；唯一推进所选历史并发布新obs_dict | 追加干净Critic帧，三帧旧到新，发布privileged_obs[N,294]；Actor噪声不污染Critic；已发布包后续不可变 |
| Runner读取观测 | `get_observations(self) -> Dict[str, torch.Tensor]`；含obs[N,1856]、privileged_obs[N,294]、obs_pred[N,12] | 只读最近包；不采噪声、不推进历史，不让Critic缺失回退到Actor |
| 环境局部reset | `reset_idx(self, env_ids: torch.Tensor) -> None`；long[K] | 先保存终止资料，再改所选物理状态／物性／命令／历史；新初帧两格零，末格真实物性；存活行不变 |
| 环境step返回终止资料 | `step(self, actions: torch.Tensor) -> Tuple[Dict[str, torch.Tensor], torch.Tensor, torch.Tensor, Dict[str, Any]]`；actions[N,14]，四项沿A04 | infos含terminal_env_ids long[K]及terminal_privileged_obs float32[K,294]、terminated／time_outs bool[N]；同设备、ids唯一且与所有done行对应，K=0提供正确空shape |
| PPO采样／更新评价价值 | `evaluate(self, critic_observations: torch.Tensor, **kwargs: Any) -> torch.Tensor`；[M,294]→V[M,1]，M可为N或终止子批K | 无观测副作用、不读取Actor latent；采样／bootstrap调用侧无梯度，value更新保留Critic梯度；非法shape／有限性失败 |

所有浮点张量为float32，显式设备一致；单位／坐标／固定缩放及接触报告含义见Q4d／Q4c。终止资料由step本地构造，不为它另建公共管理类或新控制状态；PPO如何存储／取timeout子集、compute_returns签名及完整恢复留A07。

以下为接口完整的职责伪代码，不含业务实现或新GAE公式：

```text
02配置装配
  → 校验c=98、c_frame_stack=3、C=294
  → Env与ActorCritic(num_privileged_obs=294, critic_hidden_dims=[512,256,128])

reset() → reset_idx(all_ids) → _publish_observations(all_ids)
       → (get_observations(), reset_infos)

Runner读取obs_dict_t
  → PPO.act：Actor.act(obs_t)；无梯度evaluate(privileged_obs_t)得V_t
  → env.step(actions_t)
      → 4个物理步；刷新状态／实际力／接触；按旧命令计算reward／done
      → 推进到下一边界命令
      → _build_frames(done_ids)：构造未reset终止帧
      → 由旧历史＋终止帧形成[K,294]，冻结infos及ids／标记
      → reset_idx(done_ids)
      → _publish_observations(all_ids)：各环境只追加一帧，得到next_obs_dict
      → 返回(next_obs_dict, rewards, dones, infos)
  → PPO.process_env_step：使用冻结转移和终止资料，具体回报逻辑归A07

rollout满24步
  → 存活环境evaluate最后真实后继历史
  → 纯timeout evaluate对应旧episode终止历史
  → 失败不使用后继价值延续回报
  → A07 returns／GAE，再重算evaluate(critic_batch)进行value更新

评估动作前向
  → act_inference({'obs': actor_history}, optional_policy_info)
  → 动作均值及可选12维预测，不调用Critic或读取监督真值
```

本模块测试接缝涵盖字段／坐标／缩放、17组切片、三帧旧到新与reset、命名／sim索引、真实物性来源、推理权限与梯度路径，以及旧状态／终止后继／新初帧的可辨识样例；详细独立算例见各Q。A11收束单元／整体测试与容差；形状、文档和静态XML通过不能替代Gym接触／学习验收。
