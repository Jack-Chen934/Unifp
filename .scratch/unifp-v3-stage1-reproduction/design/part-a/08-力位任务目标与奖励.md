### 推荐数值的来源与证据强弱（用户追问后补充）

用户要求详细说明为何推荐本组候选。这里区分资产直接约束、有限求解支持与工程选择；没有做过全空间边界搜索、不同范围的对照训练或几何余量标定，不能将候选写成最优或唯一合理范围。

**半径0.45—0.70m：**下限意在暂时减少靠近臂座、需要较大折叠的任务，上限意在暂时减少伸展边缘目标，给首版控制验证留空间。这是选择待核查区域的工程判断。当前名义初始TCP半径约0.799m，本身已说明0.70m不是机械臂最大半径；0.45m也不是已测出的最小可达半径。有限位置IK说明本范围有可行位置解，不证明0.40m或0.75m不可用，也未证明它比更宽范围更易学习。

**仰角0—60°：**高度差是比具体角度更直接的几何依据。当前名义球心离平地约`0.32+0.09535=0.41535m`，目标高度为`z=0.41535+r*sin(elevation)`。r=0.70m且仰角−72°时z≈−0.25039m，已经在地下；官方球心固定高度为0.8m，两平台不能只复制角度范围而忽略球心差异。官方本来也做拒绝筛查，这个例子不表示官方生成器没有处理地下候选。负角度并非全部不可用：r=0.70m、仰角−30°时z≈0.06535m，是否可执行仍取决于整个臂／工具的碰撞和动态约束。

选择0°作为首版下界，是暂时把低位、向下接近底盘／地面的复杂情况排除在随机端点域外，不是推导出所有负角度都不可行。选择60°上界，既保留明显的上下变化，也避开90°球坐标极点附近；60°是工程候选，尚未证明65°／70°不合适。首段仍允许从已验证的真实初始仰角约72.4°出发。

在水平base和上述名义球心下，本候选常规端点高度约0.415—1.022m；当前底盘碰撞盒顶面约0.345m，因此TCP点至少比名义顶面高约7.0cm。这仅描述TCP点与名义底盘顶面的关系，不能推断整臂／工具不碰撞。0.05m离地阈值在这个名义常规端点域中不是主要起约束作用的条件，不能拿它解释所有角度选择。

**方位±60°：**保留左右对称和横向操作，同时先限制在名义臂座前方。cos(azimuth)>0使相对球心的前向分量为正；官方±108°包含前后分界外的目标，需要额外核查绕机身与关节扭转等路径。±60°不是机械臂最大旋转能力，也没有证明±75°或后侧目标均不可达。该扇区并不意味着运动跨度很小：r=0.70m、仰角0°、方位±60°两端点相距约1.212m，Q1c必须结合路径跨度讨论移动时长／速度，不能只凭位置可达就接受任何时长。

**关节余量5°：**用于离线验证“目标至少存在一个不贴URDF角度限位的位置解”，避免只靠刚好在限位处的数值解支撑目标有效性。它是未标定的角度余量，不改变执行器硬限位，不保证策略会选择该关节解，也不证明速度／力矩余量或远离所有运动学奇异位形。

**TCP离地5cm：**是自由空间任务的地面间隙候选，用于将几何接近地面与正式接触任务分开，并给动态偏差留待验证的空间。它没有由实际跟踪误差分位数、制动距离或网格导入误差推导；当前名义随机端点远高于此值，其实际约束效果须结合首段／其他允许状态判断。TCP高于阈值仍不能代替整个非轮机器人几何的地面检查。

**非豁免碰撞对2cm：**是用于后续几何核查的暂定间隙，旨在避免只以“无穿透、净间隙刚好大于零”接受任务。它在本组候选中缺少直接实测支持，可能对紧凑关节装配过度保守；必须按03实际碰撞对和导入几何核验。不能把contact_offset和thickness简单相加得到2cm结论，也不能为保住该数字扩大碰撞豁免表。若与合法资产装配或必要工作空间冲突，应列出具体碰撞对和距离重新讨论，当前不视为冻结要求。

### 初始安全集合的定义

初始安全集合是允许的**完整reset状态集合**，不能只靠TCP球坐标箱定义：相同TCP位置可能对应不同碰撞状态。当前核查中心使用03名义候选：臂角`[0,1,-1.5,0,0,0]rad`，转向／驱动轮角0，夹爪固定0m，关节速度0；平地水平base，名义高度0.32m。它仍须通过03几何、轮地接触与短测冻结，Q1b不把这个中心自动视为已安全。

### A阶段的零力含义与模块边界

“零力”专指零命令力／零人工注入力，不表示取消重力或令一切真实接触力为零。重力、正常轮地接触、关节反力和意外碰撞仍通过物理仿真影响运动及已有终止／约束统计；不因此向补偿公式偷偷加入接触张量。若A真实命令／人工力缓存非零，这是阶段配置或执行错误，应报告并停止，不在补偿函数内强制清零掩盖。

### sigma数值究竟意味着什么

TCP一列均为L1误差；它不是欧氏距离。平移例子只在一个分量有误差；转向例子是单轴误差。以下列出未加权指数值，实际逐步贡献还分别乘0.04／0.04／0.02：

| 误差案例 | 公式 | 未加权奖励（约） |
|---|---|---|
| TCP L1=0.05m | exp(-2*0.05/1.0) | 0.9048 |
| TCP L1=0.10m | exp(-2*0.10/1.0) | 0.8187 |
| TCP L1=0.20m | exp(-2*0.20/1.0) | 0.6703 |
| 平移单轴误差0.10m/s | exp(-0.10²/0.25) | 0.9608 |
| 平移单轴误差0.50m/s | exp(-0.50²/0.25) | 0.3679 |
| 转向误差0.50rad/s | exp(-0.50²/0.25) | 0.3679 |

由此可见，官方TCP奖励较宽，10cm的L1误差仍约0.819，不能凭“reward较高”声称厘米级跟踪。sigma缩小会使同一误差的奖励更低且重新分配误差区间的梯度，并不自动保证更容易训练或最终更准。本题保留原值是为了先建立沿官方源码的可比基线；当前没有不同sigma／权重对照训练或动态数据证明这些值对V3最优，也没有依据将全部尺度按机械臂长度等比例缩放。A10／A11仍以m、m/s、rad/s的真实误差和任务覆盖验收，具体指标／阈值后续讨论。

## Q5c · 失败语义、缓存时序与A08完整调用链（合并方案已确认）

**合并议题：**一次确认目标筛查、运行故障、环境step／局部reset、终端价值及episode奖励／误差日志之间的完整协议，并用真实调用顺序固定接口；避免各模块分别确认后出现reset时序冲突。

**推荐答复：**采用下述分类和流程。物理episode失败／纯timeout属于训练数据；非法初态、目标筛查耗尽、shape／单位错误或非有限值属于训练级运行故障，应报上下文并停止，不转换成普通done继续。只对done环境reset；reward／误差先按旧目标和旧命令结算，terminal Critic快照按A04冻结，PPO仅对纯timeout按A07补偿。保存每个完成episode的统计后才清局部累积器。

### 故障与终止分类

| 情形 | 语义与处理 | 与训练数据的关系 |
|---|---|---|
| 单个随机目标候选未通过端点／整段筛查 | 正常拒绝；沿已确认规则重采，最多10次 | 不生成transition终止，不改采样范围或条件分布定义 |
| reset真实状态不属于已验证初始安全集合 | 训练级错误，报告env_id、root／DOF／TCP摘要、资产与配置身份，停止本次运行 | 不裁剪状态或造一个替代目标；不伪装物理episode失败 |
| 同一目标段10次候选均不合法 | 训练级筛查错误，报告段、范围及每类拒绝计数，停止本次运行 | 不只done/reset单个env后继续，不静默缩域或增加重试数 |
| A04物理失败条件 | 正常terminated；失败优先于同一步timeout，`time_outs=False` | 保留失败前真实transition／分项；不bootstrap，GAE按A04／A07遮断 |
| 纯timeout | 正常截断，`time_outs=True` | 保留reset前terminal Critic输入；A07仅由PPO在克隆reward上补偿一次，不污染环境reward |
| 输入shape／dtype／单位违反既定接口，配置非法，关键状态／reward／动作非有限，仿真数值发散 | 训练级错误；包含字段／env_ids／策略步等诊断后停止，不`nan_to_num`、裁剪成合法值或普通reset后续跑 | 错误步不进入PPO；不提交不完整训练迭代，不覆盖最近有效完整checkpoint |
| 合法的reset／目标生成或日志序列化中断 | 运行故障并停止；已经结算的完整episode记录先写入诊断／分批文件，再保留错误上下文 | 不把部分episode当成已完成样本；不丢弃前一已完成episode统计 |

该表把Q1a已确认的“最多10次耗尽即失败”、A04已确认的初始化／资产错误、物理失败／timeout优先级，以及Q5a—Q5b日志契约组合到一处；不新增目标范围或物理失败阈值。正常候选拒绝不是运行错误；高拒绝率仍需按Q1b／A11审查接受分布与训练可行性。训练级错误需保留原始异常，不强行转换成VecEnv的`done[N]`。

### 状态缓存及单步顺序

关键时间点只用以下含义：`target_t / command_t`是在动作执行期间生效、且该真实transition应追踪的旧目标／命令；`state_t1`是本次物理积分后的真实测量。当前transition的奖励、误差和episode统计均以这对数据计算。若时间表恰在该边界切换命令，则新的`command_t1`用于若episode继续时的终端Critic快照／下一观测；奖励不得偷读新命令。该约定沿A04，不让日志／新接口改变命令调度。

```text
reset_idx(env_ids):
    reset root / DOF / episode-local dynamics and histories for env_ids
    refresh real TCP and rigid-body measurements
    validate initial state against the confirmed initial safe set
    sample and screen initial target segment (up to 10 candidates)
    initialize command, target, reward/error accumulators and P95 samples
    publish one initial observation frame for env_ids

step(action[N,14]):
    validate action shape / dtype / finite values; lock target_t and command_t
    clamp action and simulate 4 physical substeps using the confirmed controller
    refresh state_t1, TCP and contact measurements; advance completed step count
    classify failure / pure timeout / alive
    compute 23-term environment reward and Q5b2 physical errors from (target_t, command_t, state_t1)
    update per-env episode reward sums and physical-error samples; stage done episode records
    advance commands / target to command_t1 for environments that would continue
    build terminal Critic snapshot before reset; freeze done infos / episode records
    reset only done envs and validate their initial state / next target segment
    publish next observations; return observations, original r_env[N], done[N], infos

Runner:
    store transition and terminal infos; PPO applies timeout-only bootstrap on its reward clone
    after full rollout/update, write iteration-level metrics and flush completed episode records
    if any training-level error occurs, stop without committing a partial iteration/checkpoint
```

若目标筛查失败发生在刚结束episode的局部reset中，环境先将已结算episode记录放入待flush记录，再抛出带上下文的运行错误；Runner捕获后先写出这批完成记录和故障诊断，再终止本轮。该错误步不冒充有效的新episode观测或交给PPO继续采样。

### 接口／数据契约

以下只确认模块边界与伪代码形状，不要求为每行新增函数；已有官方职责可直接复用。`N`为并行环境数，`K`为所选环境数，`D=14`动作维，`C=294`终止Critic特权历史；目标／状态用float32、索引long、终止bool，均在环境设备上。位置以m、力N、刚度N/m；球坐标按`[r(m), elevation(rad), azimuth(rad)]`，world位置W轴，命令力Y轴，底盘速度B轴；采样均按上述同一步快照对时。

| 接口／状态 | 契约 |
|---|---|
| `reset_idx(env_ids: LongTensor[K]) -> None` | 只复位所选环境的物理／episode状态；读取新真实状态并验证初始集合；构造新目标／命令并发布首帧。运行级错误向上传播，不产生替代episode |
| `_sample_valid_target_segments(env_ids: LongTensor[K]) -> None` | 按已确认采样域更新内部`target_start/target_end: float32[K,3]`及移动／保持计数；单候选筛除并重采；10次耗尽抛出带env／段／拒绝理由的任务筛查异常 |
| `compute_ee_compensated_target(geometric_target_world: Tensor[N,3], injected_force_world: Tensor[N,3], commanded_force_yaw: Tensor[N,3], yaw_quaternion_world: Tensor[N,4], stiffness_n_per_m: Tensor[N,3]) -> Tensor[N,3]` | 纯函数；输入分别为m、N、N、xyzw旋转和N/m；输出W轴m。shape、非有限或K<=0立即失败，不静默epsilon修补 |
| `check_termination() -> None` | 写入`terminated/time_outs/dones: bool[N]`，不reset、不改reward；失败优先。训练级错误另走异常路径，不混进该缓存 |
| `_reward_<name>() -> Tensor[N]`／`compute_reward() -> None` | 23个float32[N]分项只读当前transition缓存；有效权重含一次0.020s，产出`r_env[N]`；非有限报错 |
| `_accumulate_episode_metrics(done_ids: LongTensor[K]) -> EpisodeRecords` | 从逐环境累加器／策略边界误差样本计算完整episode字段；均值、精确P95、return／rate与结束原因沿Q5a—Q5b；先记录再只清done_ids |
| `step(actions: Tensor[N,14]) -> (ObsDict, Tensor[N], BoolTensor[N], Infos)` | 主流程如上；正常时返回原始环境reward及terminal／episode数据；训练级故障先flush已完成记录再传播，不返回伪造的普通transition |

`Infos`至少含`time_outs: bool[N]`与done终端行对齐的`terminal_env_ids: long[K]`、`terminal_privileged_obs: float32[K,294]`、逐episode结构化records；PPO bootstrap bonus单独放Runner／PPO训练诊断字段，不回写`r_env`及23项。物理误差具体均值／P95和奖励分项字段沿Q5b2／Q5b3。
