## 当前与目标调用链、模块边界及接口

当前官方链路：`get_cfgs → make_env（覆盖环境参数并设环境seed）→ make_alg_runner（覆盖训练参数与seed）→ learn`。注册器返回共享对象，类定义中的派生表达式不会随实例基础字段变化自动更新。

目标训练链路：`train_v3 → resolve_v3_configs → 启动检查与有效配置落盘 → make_env → 真实资产／观测核验 → make_alg_runner → 实际配置一致性核验 → learn`。

目标评估链路：`evaluate_v3 → 指定训练记录／检查点／协议 → resolve_v3_configs(purpose="evaluation") → 有效配置落盘 → make_env → 实际接口核验 → 同构模型加载 → 确定性评估`。模型加载和数据采样完整签名由07、10定义，本模块不增加评估框架。

## 状态与失败语义

生命周期为注册模板→本次独立副本→有效配置与快照→工厂装配与实际核验→训练／评估。有效配置形成后不改变影响初始化、布局或模型结构的字段；课程和随机化在运行期更新的状态由09定义，不把状态更新误作静默改配置。
