# A→B沿用与修改总览

日期：2026-11-07。依据当前工作树、已验收V6 A8000和固定官方源码，供B04—B11讨论前统一范围。本文记录评估和推荐，不代表未讨论的力范围、接口或验收阈值已获用户批准；本轮没有修改业务代码。

## 1. 主线结论

沿用V6资产与A8000完整学习状态，继续训练后32000轮到累计40000。网络、算法和机器人控制基线不重建；主要工作是补齐非零力的环境执行／数据闭环、A→B阶段迁移以及受力评估。架构沿用不意味着冻结网络权重；Actor、Critic、encoder和decoder继续按原PPO／辅助更新训练。

## 3. 两路力的含义

- 命令力F_cmd：任务输入，Actor可以看到；通过官方补偿目标影响学习目标，不能简单把它当作又一股物理外力叠加施加。
- 人工外力F_ext：仿真实际施加于末端的力；Actor不直接看其真值，辅助估计学习识别它，Critic训练时可使用预留真值槽。
- 物体接触反力：PhysX真实物体相互作用的结果，不等于人工注入力；真实接触评估必须独立定义测量与任务。
- A的底盘速度push：m/s单位的速度扰动，不能填入N单位的外力标签。

现有世界系补偿关系为`p_comp = p_geo + (F_ext_world + F_cmd_world) / K`。F_cmd与F_ext同坐标下相反时补偿抵消；两者不是固定等同或始终相反的两路量。B应分别测试匹配力与独立随机力，不能只测一组会抵消的条件。

## 4. 不能仅凭预留字段认定已完成的地方

1. 当前环境遇到非零力即报错，且物理循环没有施加刚体非零力；参数名接受B不等于B能训练。
2. 12维辅助标签中力组在A全零，不能证明非零估力已经学会。
3. Critic末尾变量名为compensated_target，但当前直接取commands[:,3:6]；A时二者相同，B时必须区分。
4. A恢复是完整身份一致的A→A；B源码和课程会变化，必须记录受控的阶段迁移，不可直接跳过全部哈希或只加载权重。
5. A评估阈值可以用于B后的零力回归，不能直接拿位置cm阈值代替非零估力N或物体接触力验收。

## 5. 尚需讨论、不能自动照搬的数值

官方末端cmd/ext各轴范围[-60,60]N，K=200N/m，对应单路单轴0.3m偏移；同向两路或多轴组合可能更大。A1Arm的工作空间、关节力矩与轮式支撑需要短测核对。推荐优先保留官方机制，对必须适配的范围明确说明依据，不先无证据改奖励或策略网络。

2026-11-07源码复核纠正：官方配置虽定义受力后零速度命令概率0.8，但固定副本未找到该字段读取／切换路径，实际采样使用zero_vel_cmd_prob=0.3；V6当前只连续采样速度。B的零命令分布须在B09-Q3明确确认，不能将未使用字段视为运行事实，也不能据此关闭移动受力评估。官方主step调用末端施力，而底盘施力调用被注释；底盘力字段预留不代表B应默认增加底盘N单位扰动。

新增事件状态和每步力张量远小于现有rollout；若N、观测、模型、24步rollout和8个物理子步不变，主要学习buffer尺寸不增加。实际受力可能改变接触、失败和求解成本，正式耗时／显存仍须短测，不承诺与A或官方相同。真实物体接触评估可放独立评估进程，避免无必要地给4096训练环境都加入物体。
