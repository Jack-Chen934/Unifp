# 02 分部件碰撞代理

已确认总结：按接触功能保留少量盒体、圆柱和低面数凸包，分开保护轮胎、安装间隙、关节活动空间及末端表面。形状预算和误差界限为候选，需通过几何叠图与 Gym 接触验证，用户已确认并要求实施。

## Q2 轮胎如何避免简化后滚动失真？

**推荐：**从当前已验收滚动组的接触包络提取中心、轮轴、有效半径和接触宽度；不用旧 V3 的尺寸。采用沿 link 本地 y 轴的规则圆柱凸包，初始候选为 32 个圆周采样点，两端环共 64 个凸包顶点，显式记录端面与侧面尺寸。其他凸网格同样优先控制在 64 个顶点以内，并检查实际导入／cooking 结果，避免只减少 shape 数却保留复杂凸包。

半径约 0.1m 时，32 边内接截面的理想径向离散误差约 0.48mm；实际包络误差须实测。轮中心、有效半径与接触宽度偏差初定 ≤0.5mm。保持 `replace_cylinder_with_capsule=False`，不把轮胎改为胶囊。若离散滚动产生可见抖动，先比较引擎原生圆柱和低顶点凸包的实际接触结果，不直接堆高面数。

## Q3 如何控制过度包围和漏碰？

**推荐：**代理全部在所属 link 局部坐标建立，位置单位 m、姿态为 URDF rpy rad，不跨 link 合并。不能用一个大凸包封住转向孔、臂段弯折空间或型材内孔。

末端／手指承担接触的外表面偏差候选 ≤1mm；一般外壳主要碰撞表面的偏差候选 3—5mm。采用功能表面定向检查和必要姿态的间隙检查，不要求被省略螺丝／内部零件的所有点都满足统一表面距离。相机、底盘下缘和型材仍保留主体碰撞，避免为提速直接删除有效障碍外形。

候选若出现活动空间被占用或主要表面漏碰，优先局部拆分和修形；不增加全局碰撞豁免。超出本候选预算或需要改变物理容差时，记录原因后再讨论。

## 实施记录：轮拱／轮胎局部保留

依据真实GPU pipeline的隔离对照，轮拱下缘采用原CAD组件逐字节保留，其他新增凸代理维持最多64顶点；轮胎原碰撞保留，每轮轮毂合为一个内缩凸包。最终合计80 shapes，不扩大已有局部过滤。该选择落实本议题“保护活动间隙、局部拆分”的已确认原则，未改变接触容差或算法。原始结果见实验记录 `UniFP_v3/docs/experiments/2026-11-03_v3_collision_optimization.md`。
