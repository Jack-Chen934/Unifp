# 05 单元测试与整体测试

已确认总结：验收覆盖被改变的几何、实际物性、有效碰撞、轮系响应、局部reset和正式规模性能；复用既有测试，不新增每步穷举检查。用户已确认并要求实施。

## Q1 单元测试检查什么？

**推荐：**

1. 新旧visual文件哈希、visual元素、全部joint／inertial及28link／14DOF对应关系一致；不要求collision XML一致。
2. 轮胎中心／轴线／有效半径／接触宽度及TCP接触表面，按02候选精度检查；非关键外壳采用功能包络和间隙检查。
3. 代理名称、归属link、三维凸包有效性、URDF引用文件和manifest组索引一致；检查实际所需的局部过滤映射。
4. 资产身份变化可被已有identity捕获，旧checkpoint严格resume仍被拒绝。

新增或修改函数保持完整类型标注及英文Google风格docstring。只写覆盖真实调用路径和关键回归的测试，不为复制字段或无风险辅助函数逐一镜像测试。

## Q2 整体测试检查什么？

**推荐：**

1. **外观／碰撞叠图：**零位、臂默认位、轮转向代表位、折叠臂接近底盘位；可视化代理侵占间隙或漏掉主要外表面的区域。
2. **32环境物理短测：**接地静置5秒，驱动／转向／臂小动作；检查有限状态、轮系响应、base接触与离地／穿地。实际actor逐link回读质量、COM和惯量。
3. **接触正反对照：**默认姿态无新增非相邻假接触；折叠臂对底盘能真实接触；轮地及末端对简单固定测试物体能接触。测试物体只用于独立诊断场景，不进入正式任务。
4. **局部reset：**4环境中重置一个，不污染其他root、DOF、历史观测或时钟。
5. **512同GPU对照及训练恢复：**性能比较；完整10轮更新＋新进程续1轮，双优化器、物性恢复和计数沿用既有合同。
6. **4096容量与性能：**100轮完整开发更新，正常日志／统计／保存，检查无遗漏碰撞告警，实测轮耗时及显存。

静态／名义条件和随机化条件分开记录；候选零动作失败率不能直接当作训练后S0／S1／S2失败率。短测不要求物理轨迹与旧碰撞模型逐步相等，也不将短训练奖励暂时波动设成新的启动阻断项。

## Q3 何时判定通过或需要返工？

**推荐：**外观、运动链或物性意外改变，必要自碰撞被关闭，轮地／末端接触丢失，新增默认装配穿透，或导入shape／过滤错误，均需返工；不以快代替正确。

几何通过、性能未达则记录剩余成本，局部调整代理后只重测受影响项及必要整体链路。所有结果与原始证据写入单一实验记录，最终只保留成功资产、必要回归和可追溯失败证据，清理本任务中间候选与缓存。
