# V3 训练碰撞模型优化方案

状态：**已确认，正在实施**。用户已确认优化方案并要求开始实施；当前执行票据01，候选资产尚未通过Isaac Gym动态验收。

## 总体方案

从当前已修复的桌面派生资产复制视觉、惯性和运动链，独立生成 `UniFP_v3/resources/robots/v3_a1_desktop_train_v1/`。只将逐 CAD 小零件碰撞替换为按功能分区的少量代理，预计 40—80 个 shape，实际以间隙、接触和导入结果为准。

不直接调用原生成器的 `--unsplit-collisions`：整 link 凸包会填平凹槽或安装间隙，且不能维持现有局部过滤语义。也不关闭整机自碰撞、不缩减环境数或降低物理精度来换取速度。

## 性能目标

4096 环境、每轮 24 策略步、原 PPO 与日志配置不变，完整训练平均轮耗时目标 **不超过 4.5 秒**。该值对应 A8000 更新段约 10 小时，不含创建／初始化和终点评估；只是待验证目标，不是当前已实现性能，也不认定作者的 10 小时对应同一预算。

先做同 GPU 的 512 环境新旧对照定位收益，再做新资产 4096 环境 100 轮完整开发验证，报告创建耗时、物理段、采样、更新、含写盘的实际墙钟时间、P95 和峰值显存。若未达目标，明确报告差距，不通过修改环境数、时间步或隐藏日志成本宣称达到。

## 与官方的关系

沿用官方“视觉与低复杂度碰撞表示分离”的工程思路；代理形状依据本机 V3 的几何和功能确定，不照搬 B2 的尺寸或接触点。算法层面无需为此次资产优化修改 Actor、Critic、辅助估计、PPO 或奖励。

当前 A8000 作为旧碰撞资产的独立实验保留。新资产验收后，推荐新 seed1 从头训练以保持正式复现可比性；当前旧训练的停止时间须另行明确，本轮不执行停止、热替换或新正式训练。
