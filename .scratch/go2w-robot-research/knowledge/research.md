# Go2-W 机器人调研

调研日期：2026-11-03（Asia/Shanghai）

## 摘要

宇树官方将 Go2-W 定位为搭载轮毂电机和 7 英寸充气胎的 Go2 轮式型号。官方页面公布的主要规格包括：站立尺寸 70 × 43 × 50 cm、带电池约 18 kg、供电 33.6 V、载荷约 8 kg（极限约 12 kg）、速度 0–2.5 m/s、最大攀爬落差/跨越高度小于 70 cm、最大爬坡角度 35°、16 个关节电机及最大约 45 N·m 关节扭矩。落差/跨越高度和坡度是两个不同参数；45 N·m 是页面所述最大关节电机的峰值，不能视为所有关节的额定扭矩。官方页面列有超广角 3D 激光雷达、高清广角相机、Wi-Fi 6/4G/蓝牙、二次开发支持等项目；同页提示部分功能受技术和算力限制，需要人工操作或二次开发实现。

当前可公开检索到的官方 SDK2 仓库描述为 Unitree 通用 SDK，并链接到官方开发者中心；它没有在 README 中明确声明 Go2-W 型号支持，也没有给出 Go2-W 的轮组控制接口。另在宇树官方 `unitree_ros` 仓库中找到独立的 `robots/go2w_description` ROS 描述包，包含 Go2-W URDF 和网格。由此可以确认存在公开的官方 ROS 描述模型，但不能据此确认 Go2-W SDK/API、底层控制模式、通信协议、控制频率，也不能证明 URDF 中物性和执行器字段已按实机标定。

## 功能能力与限制

- 官方产品页以“玩转全地形”为宣传语，展示全地形行驶、越障、上下楼梯、倒立等演示视频；页面分别使用“全地形通过”“征服70cm”“楼梯轻逸”“酷炫倒立”等视频标题。这些是厂商展示，不等同于每项能力均有公开的可重复测试规范。参数表另列“小于70cm”的最大攀爬落差/跨越高度与 35° 最大爬坡角度，两者不可混为同一指标。来源：[Go2-W 中文官方产品页](https://www.unitree.com/cn/go2-w)、[Go2-W 英文官方产品页](https://www.unitree.com/go2-w)、[官方页面数据模块](https://www.unitree.com/_nuxt/D5tKAvuB.js)。
- 官方功能表列出基本运动、OTA、APP、手持遥控器、前置照明、Wi-Fi 6/4G/蓝牙、语音功能和二次开发。该页的提示为：“限于目前技术和算力资源，部分功能需要人为操作或二次开发实现”。来源同上。
- 官方页面列出的扩展模块包括可选 Orin NX 等；未公开具体扩展接口、电源预算、安装约束或随机器提供的配置。来源：[官方页面数据模块](https://www.unitree.com/_nuxt/D5tKAvuB.js)。

## 开发接口与文档状态

1. [宇树官方 `unitree_sdk2` 仓库](https://github.com/unitreerobotics/unitree_sdk2) 的 README 将项目描述为 “Unitree robot sdk version 2”，提供 CMake 构建/安装步骤，并要求参考官方开发者中心；README 给出的预构建环境为 Ubuntu 20.04、aarch64/x86_64、GCC 9.4，CMake 最低 3.10。该仓库 README 没有单独列出 Go2-W、轮毂电机、转向或轮式底盘控制接口。
2. [宇树官方开发者中心](https://support.unitree.com/home/zh/developer) 是 SDK README 指向的后续文档入口。本次访问该站首页和快速开始路径时返回网站错误页（HTTP页面显示 567），因此未能核对其受限/动态加载的型号手册，也不据 SDK2 通用仓库推断 Go2-W 兼容性。
3. Go2-W 产品页声明“二次开发”，但没有公开 Go2-W 专用 SDK 包名、消息定义、控制模式、关节映射、状态反馈字段、网络拓扑、安全停机语义、通信频率或仿真描述文件。需以购买配置配套的官方二次开发手册及对应 SDK 版本核实这些信息。

来源：[SDK2 README](https://github.com/unitreerobotics/unitree_sdk2/blob/main/README.md)、[SDK2 仓库](https://github.com/unitreerobotics/unitree_sdk2)、[官方开发者中心](https://support.unitree.com/home/zh/developer)。本轮没有确认 Go2-W 专属控制示例、MJCF 或 USD 资产；这不等于官方不存在其他未公开资料。

## 官方 Go2-W ROS 模型

- 宇树官方 [unitree_ros 仓库](https://github.com/unitreerobotics/unitree_ros) 的 `robots/` 下包含 `go2w_description/`，其中有 `urdf/go2w_description.urdf`、`dae/` 网格、关节名配置、RViz/Gazebo 启动文件及 ROS `package.xml`。仓库根目录许可为 BSD 3-Clause，包的 `package.xml` 声明许可 BSD。
- 固定源码提交为 `3ae893d905d11795ddf1075825ee5010364a1109`（2026-10-30）。本地原始包位于 `UniFP_v3/resources/robots/go2w_official/robots/go2w_description/`，上游相对目录结构保留，下载文件逐个与该提交的 Git Blob SHA 核对；来源记录见同目录 `README.md`。
- 该 URDF 定义每条腿的髋、thigh、calf 旋转关节与一个连续轮关节，并有左右轮网格；四条腿共 16 个可动关节。文件内质量、惯量、关节限位及碰撞体是模型声明值，产品页未提供逐关节标定数据，故不能直接当作 Go2-W 实测物性。
- 官方 ROS 描述包是本次找到的可下载模型源；本轮没有把它转换为 Isaac USD、接入 UniFP 环境或验证物理响应。

## 与当前仓库的关系

- 当前项目文档将第一阶段范围定义为在 Ranger Mini V3 + A1Arm 上仿真复现 UniFP；轮式机器人特有创新排在第一阶段验收之后。[README.md](../../../README.md#L3)、[CONTEXT.md](../../../CONTEXT.md#L8)
- 当前工作树中可检索到的轮式适配参考是 Ranger Mini V3，而非 Go2-W。归档适配器以四个转向关节、四个驱动关节及机械臂关节构成动作名，并用 `wheel_contact` 作为 critic 输入字段。[legacy/v3_reference_20261030/ranger_unifp_vec_env.py](../../../legacy/v3_reference_20261030/ranger_unifp_vec_env.py#L34)
- 因此，Go2-W 规格可作为未来轮式平台调研输入，但不能直接替代现有 Ranger Mini V3 的资产、关节拓扑、执行器限制或已确认阶段边界。尤其产品页只公布总关节电机数，未给出关节名称、轮毂电机与腿关节控制映射，尚不足以建立策略动作/观测的仿真接口。

## 尚待一手资料核实

- Go2-W 各关节/轮端电机的名称、数量分配、减速比、持续/峰值扭矩、速度和控制模式。
- 官方底层或高层 SDK 对 Go2-W 的明确型号支持、通信协议、消息字段、控制周期和安全语义。
- 传感器具体型号、坐标系、标定参数、数据流与时间同步方式。
- URDF 中物性与碰撞参数的实机标定来源，以及其导入目标仿真器后的关节和碰撞响应。
- 载荷、续航、爬坡、越障数据对应的测试工况与销售版本差异。
- 不同电池、扩展计算模块、地区/批次和固件版本对重量、算力和接口的影响。

本笔记仅记录本次能从官方页面、官方 SDK 仓库及当前项目源码直接确认的内容；上列未确认项需要型号对应的官方二次开发手册、固件/SDK 版本说明或厂商技术答复。
